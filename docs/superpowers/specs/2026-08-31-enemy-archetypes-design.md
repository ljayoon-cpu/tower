# 확장형 적 특성 시스템 설계

## 목표

빠르게 적을 처치하는 손맛을 유지하면서, 후반 스테이지에서는 한 종류의 타워만으로 높은 별을 얻을 수 없게 만든다. 새 챕터와 스테이지는 코드 분기 대신 적 정의와 웨이브 데이터 조합으로 제작한다.

## 범위

이번 버전은 지상 적만 실제 전투에 넣는다. 모든 적 정의에는 미래 공중 콘텐츠를 위한 `movementLayer: 'ground' | 'air'`를 두되, 공중 경로와 공중 전용 타워는 다음 콘텐츠 버전에서 구현한다.

## 적 공통 데이터

`EnemyDef`는 기존 체력·속도·보상에 다음 선택 속성을 더한다.

- `armor`: 공격 한 번에서 먼저 차감되는 고정 방어. 저격의 관통 수치는 이를 무시한다.
- `shield`: 체력보다 먼저 닳는 에너지. 마지막 피격 뒤 지연 시간이 지나면 초당 회복한다.
- `regenPerSecond`: 보호막이 없는 동안 회복하는 체력. 독 상태에서는 0이 된다.
- `summon`: 생존 중 일정 주기로 부하를 앞쪽에 소환한다. 소환 부하는 웨이브 완료 수에 포함되지 않는다.
- `interceptor`: 일반 표적 우선순위보다 먼저 공격 대상으로 선택되는 부하 플래그다.
- `movementLayer`: 현재는 ground만 사용한다.

웨이브 그룹은 `hpMultiplier`, `speedMultiplier`, `shieldMultiplier`를 선택적으로 받아 같은 적을 챕터 후반에서도 재사용한다.

## 전투 상성

| 타워 | 명확한 역할 | 적 상호작용 |
|---|---|---|
| 화살탑 | 빠른 지속 공격 | 보호막 재충전을 계속 끊고 부하를 빠르게 정리 |
| 대포 | 밀집 처치 | 군집충과 소환 부하를 폭발 한 번으로 정리 |
| 서리탑 | 돌진 차단 | 빠른 돌진병의 경로 통과 시간을 늘려 다른 타워에 시간 제공 |
| 번개탑 | 연결된 다수 처리 | 여러 적이 몰린 보호막 편대의 에너지를 연쇄로 빠르게 소진 |
| 저격탑 | 장갑·정예·보스 저격 | 높은 한 발 피해와 방어 관통으로 장갑 정예를 처리 |
| 독 타워 | 재생 차단·범위 지속 피해 | 재생체의 회복을 중단하고 군집을 지속적으로 약화 |

상성은 특정 타워가 없으면 진행 불가능한 하드 락이 아니다. 단일 타워 조합은 후반에서 1별 정도까지 가능하지만, 서로 다른 두세 역할을 섞어야 안정적인 2~3별이 나온다.

## 적 아키타입

- **돌진병**: 높은 속도와 낮은 체력. 서리 효과 아이콘과 발자국 잔상을 표시한다.
- **군집충**: 낮은 체력으로 빠르게 뭉쳐 나온다. 작은 원형 실루엣과 개체 수가 손맛을 만든다.
- **방어막병**: 파란 에너지 막과 별도 보호막 바를 가진다. 피격이 끊기면 보호막을 충전한다.
- **장갑 정예**: 회색 장갑 수치가 피해를 감소시킨다. 피격 때 장갑 금이 보이고, 저격은 관통 표식을 낸다.
- **재생체**: 녹색 회복 고리와 체력 회복 애니메이션을 가진다. 독중독 고리에서는 회복이 멈춘다.
- **소환사**: 일정 시간마다 작은 부하를 현재 위치보다 앞에 소환한다. 부하는 적 공격을 먼저 받아 소환사를 보호한다. 부하는 보상은 주지만 웨이브 클리어 조건을 지연시키지 않는다.

## 전투 표현과 손맛

- 보호막 피해는 파란 균열과 짧은 숫자 팝으로 표시한다.
- 장갑에 막힌 피해는 둔탁한 회색 스파크, 관통 공격은 보라색 관통선으로 표시한다.
- 재생은 초록 펄스, 독으로 차단될 때는 보라·초록 파열로 표시한다.
- 소환사는 생성 직전에 바닥 문양을 보이고, 부하는 빠르게 튀어나와 전방을 막는다.
- 적이 처치될 때 현재의 팝·골드 표시를 유지하며, 특성별 파열 효과를 겹친다.

## 밸런스와 스테이지 제작 규칙

- 1챕터 후반은 돌진병·군집충·방어막병·장갑 정예·재생체·소환사를 섞는다.
- 보스 웨이브는 보스 하나만 크게 만드는 대신 소환사나 돌진병을 함께 넣어 표적 전환을 요구한다.
- 새 스테이지는 적 키와 배율, 수량, 간격만 조합한다. 새 코드 없이 난이도를 올릴 수 있어야 한다.
- 테스트는 마지막 스테이지에서 모든 단일 타워 전략의 별이 1 이하인지 확인하고, 지정 혼합 머지 전략이 2별 이상인지 확인한다.
- 무방어 전략은 모든 스테이지에서 패배해야 하며, 동일 시드는 항상 같은 결과를 내야 한다.

## 검증

- 순수 전투 규칙 테스트: 장갑, 보호막 재충전, 독 재생 차단, 소환 주기와 부하 표적 우선을 각각 검증한다.
- 엔티티 테스트: HUD 값과 시각 상태가 적 상태에 맞게 바뀌는지 검증한다.
- 밸런스 시뮬레이션: 1-1부터 최신 스테이지까지 세 시드로 단일·혼합 전략을 비교한다.
- 브라우저 확인: 420×840 세로 화면에서 보호막 바, 상태 아이콘, 소환 부하, 처치 이펙트가 겹치지 않는지 확인한다.
