# 전장 랜드마크·챕터 진행 지도 설계

## 목표

월드 1·2의 타일 위에 적의 침입구와 지켜야 할 코어를 명확히 표시하고, 각 스테이지와 보스전을 다른 장소로 느끼게 한다. 스테이지 선택 화면에는 챕터 이동 경로를 추가한다.

## 범위

* `StageDef`의 기존 `id`, `spawn`, `goals`, `bossStage`, `grid`만 읽는다. 웨이브·경로·보상·밸런스는 변경하지 않는다.
* 월드 1은 성문 침입구, 청록 수호 코어, 횃불/폐허를 쓴다. 월드 2는 압력관 입구, 용광로 코어, 수정/배기관을 쓴다.
* 보스전에는 코어 주변의 경고 고리와 월드별 전투 표식을 추가한다.
* 스테이지 선택 상단에는 잠금 상태와 해금 진행을 반영하는 비대화형 챕터 경로를 둔다.
* 새 래스터 에셋, 전투 중 지속 생성되는 이펙트, 입력 오브젝트는 추가하지 않는다.

## 렌더링 구조

`WorldMapPainter`는 `drawStageLandmarks(stage)`로 입구·목표 코어·일반 랜드마크·보스 장식을 한 정적 Graphics에 그린다. 순수 함수 `battlefieldLandmarkKind`와 `landmarkCells`는 월드/스테이지 ID와 타일 그리드만으로 결과를 결정해 재시작해도 배치가 바뀌지 않는다.

장식은 기존 타일 입력을 바꾸지 않으며 타워(8 이상), 적(4 이상), 투사체(20)보다 낮은 depth를 쓴다. 일반 랜드마크는 최대 네 개이고, 입구 하나와 목표당 코어 하나만 더한다.

`WorldProgressMap`은 StageSelect 상단에만 정적 Graphics와 텍스트를 만든다. 기존 카드 잠금·스크롤·전환에 관여하지 않는다.

## 시각 규칙

| 요소 | 월드 1: 국경 성벽 | 월드 2: 붉은 용광로 |
| --- | --- | --- |
| 침입구 | 성문, 차가운 횃불 | 압력관, 주황 고리 |
| 목표 | 청록 수정 코어, 방벽 | 타오르는 용광로 심장 |
| 일반 랜드마크 | 망루 횃불 또는 부서진 비석 | 수정 군집 또는 증기 배기관 |
| 보스 표시 | 진홍 깃발, 코어 경고 원 | 경고 링, 열기 배출구 |

## 검증

* 일반 랜드마크는 BUILDABLE 타일에서만 선택되고 결과가 결정적이어야 한다.
* `npm test`, `npm run build`, `tests/balance/balance.test.ts`를 실행한다.
* 420×840에서 챕터 1 일반전과 보스 카드/전장을 열어 입구·코어·랜드마크·진행 지도의 겹침과 콘솔 오류를 확인한다.
