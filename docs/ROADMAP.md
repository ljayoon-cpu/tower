# 로드맵 / 방향

작성 2026-08-31. 작업 규칙은 [/AGENTS.md](../AGENTS.md).

## 큰 목표

**100만 명이 다운받아 재밌게 하는 게임.** 지금은 코어 루프(설치·머지·판매·웨이브 방어)가
돌아가고 월드 2까지 콘텐츠가 있다. 대중성·리텐션을 끌어올리는 게 다음 단계.

## 원칙

1. **머지가 핵심 재미.** 새 수치·기능은 "넓게 깔기 vs 높게 쌓기" 선택을 더 흥미롭게
   만드는지로 판단. 스프레드가 다시 지배적이 되면 후퇴.
2. **로직은 순수 TS + Vitest.** 밸런스 변경은 `tests/balance` 시뮬로 뒷받침.
3. 텍스처는 전부 `generateTexture` 도형 — 나중에 도트/일러스트로 교체해도 키만 유지하면 로직 불변.

## 완료

- 코어: 그리드·경로·웨이브·이코노미·머지·타겟팅, 4→6종 타워(+저격·독), 적 3종+보스, 별점·저장·PWA
- 콘텐츠: 월드 1 (1-1~1-8), **월드 2 (2-1~2-4, 붉은 동굴 테마)**
- 가독성: 적 체력바, 타워 정보 패널(DPS·다음레벨·사거리·판매가·표적), 웨이브 미리보기, 보스 체력바
- 손맛: 타워 조준 회전, 처치 팝·플로팅 골드, 머지 팝, 피격 플래시·착탄 링, 프로스트 오라, heavy 히트 셰이크
- 시스템: **웨이브 자동 시작(카운트다운+지금시작)**, 3x 배속, **타워 이동 배치**, **웨이브 클리어 이자**,
  표적 우선순위(선두/후미/최대체력/최근접), 일시정지 타워 구성 표시
- 밸런스: 고레벨 타워 상향으로 머지 > 스프레드 (시뮬 회귀 단언), 전 스테이지 시뮬 튜닝

## 다음 (100만 다운로드 관점, 우선순위 순)

### 1. FTUE / 튜토리얼 (가장 중요) — 미착수
새 플레이어가 그리드만 보고 탭·드래그·롱프레스를 스스로 알아내야 함. 이탈 1순위.
- 1-1 첫 진입 시 단계별 안내: "빈 칸을 눌러 화살탑 설치" → "같은 타워를 겹쳐 합체" → "다음 웨이브"
- 손가락/화살표 힌트, 첫 웨이브 전 강제 일시정지
- `save.ts`에 `tutorialDone` 플래그

### 2. 리텐션 훅 — 미착수
- 메타 진행: 판마다 버는 재화로 영구 업그레이드(시작 골드+, 타워 해금, 라이프+)
- 도전 과제 / 일일 도전
- 무한 웨이브 모드 (한 맵, 죽을 때까지)

### 3. 새 적 1종 (Codex 담당) — 진행 중
방어막/장갑/분열 등. `Enemy.ts`·`types.ts`·`textures.ts`를 Codex가 만짐 → 다른 작업은 이 파일 피할 것.

### 4. 폴리시
- 메인메뉴·씬 전환 연출, 배경, 파티클
- 월드 2 이후 월드 3
- 스테이지 선택 월드 구분(탭/섹션)

### 5. 배포 (실기기 필요 — 사용자)
- 안드로이드/iOS PWA 설치·오프라인·터치 확인, 중급 안드로이드 프레임 측정
- `feat/pages-deploy` 브랜치에 GitHub Pages 자동배포 워크플로 대기 중 (레포 Settings→Pages→Source: GitHub Actions 한 번 필요)
- Vite 청크 경고: Phaser 포함 ~1.24MB(gzip ~331KB) — 코드 스플릿 검토
- Capacitor APK (폴더 구조만 대비)

## 알려진 갭 / 리스크

- 밸런스 시뮬 전략은 순진함(고정 타일 우선순위, 판매·중간구매 없음). 사람 실력의 하한선일 뿐.
  수치를 시뮬만 보고 과조정 금지. 실제 플레이 감은 사용자 컴퓨터 검증으로.
- **데스크톱 브라우저 검증 ≠ 폰 검증.**
- 사운드는 절차적 합성(`scripts/generate-sfx.mjs`), `SOUND_ENABLED`로 완전 비활성 가능.
- Codex가 `main`에 직접 push하는 경향 있음 — 충돌 시 리베이스로 수습 중.
