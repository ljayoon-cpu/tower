# 구현 및 검증 기록 — 2026-08-31

## 반영한 기능

- 게임 시간 기준 1x/2x 이동·발사·감속, 일시정지·재개·포기.
- 클리어/실패 결과 화면, 라이프 기반 별점, 최고 기록 저장, 다음 스테이지 해금.
- 투사체 풀링, 재사용 시 표적·콜백 초기화, 표적 소멸 시 마지막 위치까지 이동.
- 번개 전이는 발사 시점이 아닌 착탄 시점의 적 위치·생존 상태로 결정.
- PWA 매니페스트, 아이콘, 서비스워커와 오프라인 프리캐시 빌드.
- 효과음은 승인된 선택 범위에 따라 생략(`SOUND_ENABLED = false`).

## 사용자 결정

합친 타워도 판매 시 **Lv1 설치비의 60%만 환급**한다. 합치기에 쓴 비용은 손실로 남겨 판매와 재배치에 부담을 둔다. 화살탑은 Lv1~5 모두 30G를 환급한다. 난이도 수치는 임의로 완화하지 않았다.

## 자동 검증

- Vitest: 18개 파일, 78개 테스트 통과.
- TypeScript 검사와 Vite 프로덕션 빌드 통과.
- 매니페스트·서비스워커·192/512 아이콘 생성 확인.
- `git diff --check`: 공백 오류 없음.
- Phaser를 포함한 약 1.23MB JS 청크에 Vite 크기 경고가 남아 있다(압축 약 330KB).

## 브라우저 검증

- 4종 타워 설치, 같은 타워 합치기, 빈 칸 드롭 시 원위치 복귀.
- 합친 화살탑 길게 누르기 → 별도 확인 클릭 → 30G 환급 → 빈 타일 재설치.
- 2x 전투, 일시정지 팝업과 재개.
- HUD 위에서 드래그를 놓아도 버튼을 잘못 누르거나 드래그 상태가 남지 않음. 후속 드래그도 정상 동작.
- 저장한 별점과 해금 상태를 새 페이지의 스테이지 선택 화면에서 복원.
- 프로덕션 빌드의 1-1을 4종 타워와 화살탑 합치기로 플레이: 라이프 19/20, 별 2개로 클리어. 다음 스테이지 버튼으로 1-2 진입 확인.
- 1-2에서 방어하지 않아 라이프 0/20으로 실패: 별 0개, 다음 스테이지 버튼 없음. 다시 하기로 골드 230·라이프 20·배속 1x·빈 보드 복원 확인.
- 재시작 후 일시정지 → 포기로 스테이지 선택 복귀. 새로고침 후에도 1-1 별 2개, 1-2 별 0개, 1-3 잠금 유지 확인.
- 위 프로덕션 브라우저 점검의 오류 로그 없음.

## 아직 확인하지 않은 범위

- 실제 Android/iOS에서 설치, 오프라인 재실행 및 터치 조작.
- 중급 Android에서 60기 이상 적이 동시에 있을 때 프레임 측정.

## 2-5 (지휘관 보스) 밸런스 — 사람 플레이테스트 필요

카운터플레이 적(방어막·재생·소환)과 페이즈 보스가 있어 `tests/balance` 시뮬의 순진한
전략으로는 클리어 불가. 스크립트로 "숙련자 상정 방어"(넉넉한 골드 + Lv3~4 조합 머지
10기: 대포·저격·독·냉기·번개 혼합)를 짜서 돌리면 8웨이브 전부 클리어(라이프 14/20).
즉 **구조적으로 클리어 가능하지만 강한 조합 머지가 필요**. 실제 손 플레이로 초반 경제 흐름이
빡빡하지 않은지 확인해야 한다.

데스크톱 브라우저 확인을 휴대폰 성능·설치 검증으로 간주하지 않는다.
