# 세계관 — 태엽 군단 vs 마법 첨탑

다크 판타지. 마법이 저무는 시대, 강철이 밀려온다.

## 큰 줄기

옛 왕국은 **정수맥(ley-line)** 위에 세워졌다. 국경을 따라 세운 **마법 첨탑**은 이 땅의
마력을 끌어올려 침입자를 태워버리는 마지막 방벽이었다. 관리인은 첨탑에 마력을 흘려넣고,
필요하면 약한 첨탑 둘을 **합쳐(merge)** 더 높은 하나로 세운다 — 흩어진 여러 통로보다
한 곳에 모은 통로가 훨씬 세기 때문이다.

이제 산 아래 깊은 **용광로**에서 **태엽 군단(Clockwork Legion)** 이 올라온다. 왕도, 두려움도,
자비도 없는 기계 군세. 한 웨이브는 새 생산 라인 한 번. 목표는 단 하나 — 모든 첨탑을 뚫고
정수맥을 말려버리는 것.

플레이어는 마지막 **탑지기(warden)**. 정수맥이 마르면(라이프 0) 그 구역은 함락된다.

- **캠페인**: 국경 성벽(월드 1) → 용광로 심장부(월드 2) → 구름 위 부유 병기창(월드 3)까지 밀고 들어가 생산을 끊는다.
- **무한 모드**: 용광로는 멈추지 않는다. 마지막 첨탑 하나로, 점점 커지는 생산 라인을
  죽을 때까지 버틴다.

## 월드

| 월드 | 장소 | 분위기 |
|---|---|---|
| **1** | 국경 성벽 · 밤의 평원 | 군단의 선봉대가 프론티어를 넘는다. 검푸른 밤, 능선 실루엣. |
| **2** | 붉은 용광로 동굴 | 군단이 태어나는 곳. 용암 불빛, 강철 천장. 피날레 보스 = 공성 지휘관. |
| **3** | 구름 위 · 부유 병기창 | 용광로를 뚫자 군단이 산정상에서 비행 편대를 띄운다. 찬 청회색 하늘, 강철 비행선 실루엣. 피날레 = 공중 기함. |

## 태엽 군단 (적)

전부 기계. 이름은 냉정한 군용 제식명 + 약간의 위협감.

| key | 이름 | 정체 |
|---|---|---|
| `normal` | 보병 오토마톤 | 태엽으로 걷는 기본 보병 |
| `fast` | 추적 사냥개 | 네 다리 추격 병기, 빠르고 물렁 |
| `tank` | 공성 골렘 | 두꺼운 장갑, 정면 단발을 튕겨낸다 → 파열탑(광역)이 답 |
| `shield` | 역장 보병 | 에너지 방벽 발생기. 단발을 잘 막음 → 번개(연쇄)가 무너뜨림 |
| `regenerator` | 수복 그럽 | 나노 수복 벌레. 순간 화력은 갉힌다 → 역병(지속)만이 이김 |
| `summoner` | 균열 조립기 | 이동식 조립 포탈. 계속 부하를 뱉음 → 빨리 끊어라 |
| `minion` | 조립 드론 | 균열 조립기가 뱉는 잡졸. 직격 우선 방어 |
| `boss` | 공성 지휘관 | 군단 지휘 기갑. 체력 구간마다 돌격·재방벽·증원. 한 종류로는 못 뚫는다 → 마광탑 |
| `splitter` | 분해 유닛 | 파괴되면 그 자리에서 조각 셋으로 분해 (무한 40+) |
| `berserker` | 과부하 병기 | 손상되면 회로가 폭주해 가속 (무한 40+) |
| `crusher` | 파쇄 전차 | 준보스급 벽. 느리고 모든 공격 반감 → 지속 집중빔 (무한 40+) |
| `drone` | 정찰 비행체 | 낮게 나는 감시 드론 편대. 물렁하고 빠름 (공중) |
| `gunship` | 포격 비행정 | 장갑 두른 공중 포대. 느리고 단단 (공중) |
| `carrier` | 강하 수송선 | 격추되면 지상 잡졸 셋을 떨군다 (공중) |
| `airboss` | 공중 기함 | 월드 3 피날레. 급강하·편대 전개. 대공 첨탑이 답 (공중) |

## 마법 첨탑 (타워)

정수맥의 마력을 쓰는 아케인 방어탑. `key`는 코드 참조용이라 고정, `name`만 세계관에 맞춘다.

| key | 이름 | 역할 |
|---|---|---|
| `arrow` | 화살탑 | 마력 화살, 기본 단발 딜 |
| `cannon` | 파열탑 | 파열 룬을 던져 뭉친 적을 한 번에. 3·5합 = 방어구 파괴 |
| `frost` | 서리탑 | 감속·빙결. 추격 사냥개 카운터 |
| `bolt` | 번개탑 | 연쇄 방전. 역장 보병 카운터 |
| `sniper` | 저격탑 | 마안이 먼 곳을 꿰뚫는다. 관통·처형 |
| `poison` | 역병탑 | 부식 안개 지속 피해. 수복 그럽 카운터 |
| `laser` | 마광탑 | 집속 마력빔, 한 대상을 계속 지질수록 강해짐. 보스·파쇄기 카운터 |
| `command` | 지휘탑 | 룬 각인으로 주변 첨탑 강화 (직접 화력 미약) |
| `mine` | 연금탑 | 마력을 금으로 치환, 초당 골드 생성 |
| `ballista` | 창공탑 | 대공 첨탑. 공중에 압도적, 지상엔 약함. 3·5합 = 공중 다중 사격 |

### Lv3 분기 경로 (6종 전투탑)

Lv1~2 는 공통, Lv3 에서 A/B 두 방향 중 하나를 고른다. `key`('a'/'b')는 고정, 이름만 세계관.

| key | A 경로 | B 경로 |
|---|---|---|
| `arrow` | 연발형 (멀티샷) | 관통형 (방어구 관통·직선 다중) |
| `cannon` | 제압형 (방어 파괴) | 융단형 (착탄 후 광역 화상) |
| `frost` | 빙결형 (적중 누적 빙결) | 냉기장형 (주변 전체 지속 감속) |
| `bolt` | 과부하형 (연쇄 경직) | 직격형 (단일 방어막 무시 강타) |
| `sniper` | 처형형 (저체력 마무리) | 관통형(레일건) (직선상 전원 관통) |
| `poison` | 부식형 (방어 무시 중독) | 역병확산형 (중독 주변 전염) |

## 규칙 (밸런스 철학과 연결)

- 합치기(머지)가 정체성. 흩어진 약한 첨탑보다 몇 기를 높게 세우는 게 골드당 세다.
- 적마다 뚜렷한 카운터 첨탑이 있다(`EnemyDef.resist`). 한 종류 스팸으로는 후반이 안 뚫린다.
- 난이도는 임의로 완화하지 않는다. (docs/verification-2026-08-31.md)
