# 머지 타워디펜스

Phaser 3, TypeScript, Vite로 만든 세로형 모바일 머지 타워디펜스입니다.

개발/이어작업 가이드는 [AGENTS.md](AGENTS.md), 앞으로의 방향은 [docs/ROADMAP.md](docs/ROADMAP.md)에 있습니다.

## 조작

- 빈 칸을 누르고 타워를 골라 설치합니다. 회색으로 표시된 타워는 골드가 부족합니다.
- 같은 종류·같은 레벨의 타워를 겹쳐 합칩니다. 최대 Lv5이며, 빈 칸으로 옮기는 기능은 없습니다. 드래그 중에는 합칠 수 있는 타워가 초록 링으로 표시됩니다.
- 타워를 한 번 누르면 사거리와 함께 이름·레벨·DPS(다음 레벨 DPS)·판매가가 뜹니다.
- 합치기 비용은 레벨마다 2배로 늘지만 화력은 그보다 가파르게 오릅니다. 자리를 넓게 깔기보다 몇 기를 높게 쌓는 편이 골드당 화력이 세고, 탱커·보스를 녹이려면 사실상 머지가 필요합니다.
- 타워를 길게 누르면 판매 확인창이 열립니다. 판매 금액은 레벨에 관계없이 **Lv1 설치비의 60%**입니다. 합치는 데 사용한 비용은 돌려받지 못합니다.
- `다음 웨이브`로 전투를 시작하고 `1x / 2x`로 배속을 바꿉니다. HUD에 다음 웨이브의 적 구성이 미리 표시되고, 보스가 나오면 상단에 보스 체력바가 뜹니다. 일시정지에서 재개하거나 스테이지 선택으로 돌아갈 수 있습니다.
- 살아남아 모든 웨이브를 끝내면 남은 라이프에 따라 별을 얻고 다음 스테이지가 열립니다. 최고 별점은 같은 브라우저에 저장됩니다. 브라우저 저장소를 차단하거나 지우면 기록이 유지되지 않을 수 있습니다.
- 월드 1은 1-1 ~ 1-6이며, 1-6은 보스 4기가 나오는 피날레입니다.

- 메인 메뉴와 게임 상단의 `소리 켜짐 / 꺼짐` 버튼으로 효과음을 조절합니다. 음소거 설정도 같은 브라우저에 저장됩니다.

## 효과음

화살·대포·냉기·번개 공격, 적 처치·라이프 손실, 설치·합치기·판매, 웨이브 시작·승리·패배·버튼 효과음 13종을 직접 합성했습니다. 외부 녹음이나 샘플을 사용하지 않았습니다. 브라우저의 자동 재생 정책에 따라 첫 클릭/터치 이후 소리가 납니다.

`public/sfx/`에 WAV 파일을 포함하며 PWA 프리캐시에도 넣습니다. `npm run sfx:generate`로 같은 파일을 다시 생성할 수 있습니다. 반복 공격음은 재생 간격을 제한하고 동시에 최대 8개만 재생합니다. 개발자가 완전히 비활성화하려면 `src/core/constants.ts`의 `SOUND_ENABLED`를 `false`로 바꿉니다.

## 실행

```bash
npm i
npm run dev
```

브라우저에서 표시된 로컬 주소를 엽니다(예: `http://localhost:5173/`). `index.html` 파일을 직접 여는 방식은 지원하지 않습니다. 휴대폰에서 확인하려면 `npm run dev -- --host`로 같은 Wi-Fi의 기기에서 접속합니다.

## 빌드와 테스트

```bash
npm run build
npm run preview -- --host
npm test
```

빌드 결과는 `dist/`에 생성됩니다. PWA 설치와 서비스워커 오프라인 동작은 HTTPS 환경에서 확인해야 합니다. 로컬 개발 중에는 `localhost`가 예외이며, 휴대폰의 HTTP 접속은 설치 기능이 제한될 수 있습니다.

스테이지 데이터는 `src/data/stages/`, 타워 정의와 성장 수치는 `src/data/towers.ts`에 있습니다. `tests/balance/`는 Phaser 없이 전투를 시뮬레이션해 난이도를 측정합니다. 회귀 테스트는 "방어 안 함"이 항상 지고 마지막 스테이지에서 머지가 넓게 깔기보다 나은지 확인합니다. `BALANCE_EXPLORE=1 npm test`로 수치 후보 비교를 돌릴 수 있습니다(`docs/balance-*.json`은 재생성 산출물이라 git에서 제외).

APK로 패키징하려면 Capacitor를 추가해 Android 프로젝트를 생성하면 됩니다.
